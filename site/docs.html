Everything kyfram understands: scripts, kinds, props, flags. The mental model is CSS @keyframes applied to video files.

Install

curl -fsSL https://codetesla51.gitlab.io/kyfram/install.sh | sh

Needs Go 1.25+, ffmpeg + ffprobe on PATH. Optional: edge-tts + python3 for neural voice, espeak-ng for local fallback. Neither is required, beeps work offline.

Or build by hand: git clone https://gitlab.com/codetesla51/kyfram, go mod download, go build ./....

Scripting in Logos

Times are quoted-string seconds. Logos has no duration literals, so "0" and "1.5" are keys, never 0s. Keyframes sort by time, declare in any order.

scene(3, 30)                              -- duration, fps
shape("b", "circle", table{               -- name, kind, keyframes, optional group
    "0": table{x: 80, y: 240, r: 40, color: "#e64c40", ease: "easeInOut"},
    "3": table{x: 560, y: 240, r: 40, color: "#40e680"},
})
text("t", table{                          -- kind implied
    "0": table{content: "go", x: 320, y: 60, size: 48, color: "#ffffff", font: "/path/to.ttf"},
})
group("g", table{"0": table{x: 320, y: 180, scale: 1, rotate: 0}})
shape("c", "circle", table{"0": table{x: 0, y: 0, r: 20, color: "red"}}, "g")
audio("/path/to.mp3", 1.0)                -- path, offset, optional loop bool
camera(table{"0": table{x: 320, y: 180, zoom: 1}, "2": table{x: 400, y: 180, zoom: 1.2}})

let v = tts("hello world", "/tmp/out.mp3")                          -- default voice en-US-AriaNeural
let v = tts("hello world", "/tmp/out.mp3", "en-US-JennyNeural")     -- string shorthand
let v = tts("hello world", "/tmp/out.mp3", table{voice: "en-NG-EzinneNeural", rate: "+10%"})
let voices = tts_voices()                 -- list Edge voices
let copy = text_file("assets/copy.txt")   -- 1 MB cap, frozen at build time

use "helpers/spike"                       -- inlines helpers/spike.lgv beside the script

Numbers lerp, hex and named colors lerp per channel, point arrays lerp elementwise, strings snap to the earlier key. Out of range holds the edge, never extrapolates. Easing per segment: linear easeIn easeOut easeInOut cubicIn cubicOut cubicInOut sine, declared on the earlier key as ease: "easeIn".

Kinds and props

x/y in pixels, origin top-left. Unknown kinds and unloadable assets skip silently. Every vector kind takes alpha 0-1, rotate degrees, scale, layer, ease.

KindProps
circlex y r color
rectx y (top-left) w h color
roundRectx y w h radius color
polygonpoints [x1,y1,…] color filled? width
starx y r points inner color
ellipsex y rx ry color (ry defaults to rx)
linex1 y1 x2 y2 width color
arcx y r start end (degrees) width color
wavex y width amplitude frequency phase thickness color
pathpoints width color filled? closed? cap join
imagepath x y (centered, ignores alpha)
textcontent x y size color font? (points rides a path)
groupchildren keep local x/y; scale/rotate/alpha multiply

Gradients on filled kinds: gradFrom gradTo + gradAngle. Blend on any entity: blend: "multiply" | "screen" | "add". 24 named colors resolve to hex and lerp like hex.

CLI reference

kyfram render [--out f] [--fps n] [--width n] [--height n] [--font f]
              [--crf n] [--preset s] [--format mp4|png] [--var k=v ...] <script.lgv>
kyfram view [--port n] <script.lgv>
FlagMeaning
--outoutput path (default out.mp4)
--fps --width --heightoverride scene rate and canvas (default 640x360)
--fontfallback typeface, must be .ttf
--crfx264 quality 0-51, lower is better (18 high, 23 default, 28 small)
--presetultrafast..veryslow (medium default)
--formatmp4 via ffmpeg, or png single frame at t=0 with no ffmpeg
--var k=vrepeatable template vars, one script renders many videos

How it works

.lgv script → LoadScript (inline use) → vm.Run → Builder (Timeline)
          → Interpolate(t) → gg canvas → ffmpeg stdin → out.mp4

Load inlines use. Declare keeps only scene/shape/text/group/audio/camera/tts calls, everything else runs and is ignored. Interpolate blends the two surrounding keyframes per entity per frame. Rasterize paints one RGBA canvas per frame. Encode streams raw pixels to ffmpeg; short audio is padded, looped tracks repeat to the last frame.

Run any: kyfram render examples/<name>.lgv --out /tmp/<name>.mp4. Scripts are declarations only by convention. Sandbox blocks file IO, network, shell, exit.

Limits, honestly

2D screen space only. Groups are flat, one level. Gradient fills on filled kinds, strokes and images stay flat. Audio loops whole files. TTS needs network for neural, otherwise local voice, otherwise beeps.

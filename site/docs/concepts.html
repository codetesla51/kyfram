Why it exists

Imperative video code interleaves what to draw with when to draw it. Retiming, reordering, and batch templating get expensive: you chase timers and callbacks. kyfram collapses that to data, a Timeline of duration, rate, entities, groups, audio, camera. Sequencing becomes a pure function of time.

Interpolation

Per entity per frame, the two surrounding keyframes blend. f = (t-t0)/(t1-t0), reshaped by the earlier key's ease curve. Numbers lerp, colors lerp per channel, arrays lerp elementwise, strings snap to the earlier key. Past the last key holds the last value, never extrapolates. Empty input returns empty.

Pipeline

Loadinlines local use statements, Go-side, Logos never forks
Declareruns the script, keeps only declaration calls in the Builder
Interpolateblends keyframes per entity per frame
Rasterizepaints one RGBA canvas per frame: camera, groups, entities
Encodestreams raw pixels to ffmpeg stdin; png skips ffmpeg entirely

Zero-disk render path. PNG sequences exist only as a debug path. Images decode once per process, not per frame.

Sandbox

Scripts run sandboxed: no file IO, no network, no shell, no exit. Logos file reads stay blocked. text_file and tts are the narrow allowed builtins. Scripts are declarations only by convention. The sandbox cannot block for and if, the builder simply ignores everything except declarations.

Limits

2D screen space only, no 3D, streaming, or GUI editor. Groups are flat, one level. Gradient fills on filled kinds, strokes and images stay flat. Audio loops whole files, no per-section repeat. Fonts must be .ttf.

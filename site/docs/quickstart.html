Quickstart.

One script, one render, one preview. Two minutes.

Overview Install Quickstart Scripting Kinds CLI Examples Concepts

1 · Write a script

Save as intro.lgv. A ball glides left to right over two seconds at thirty frames.

intro.lgv 
scene(2, 30)

shape("ball", "circle", table{
    "0": table{x: 100, y: 180, r: 40, color: "#e64c40"},
    "2": table{x: 540, y: 180, r: 40, color: "#e64c40"},
})

2 · Render it

kyfram render intro.lgv --out out.mp4

Higher quality: --crf 18 --preset slow. One still frame, no ffmpeg: --format png --out frame.png.

3 · Preview it live

kyfram view intro.lgv

Opens localhost:8080. Scrub slider, play button, hot reload. Save the file and the preview follows, no re-encode.

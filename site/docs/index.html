What kyfram is

kyfram is a small, opinionated engine for motion graphics and stills. You declare what shapes look like at specific times in a .lgv script. Go interpolates between keyframes, rasterizes each frame in memory, and pipes raw pixels to ffmpeg for video or writes a single png.

The mental model is CSS @keyframes applied to video files. Imperative tools make you sequence commands. Here you declare states at times and the engine owns all sequencing and tweening.

.lgv script → LoadScript (inline use) → vm.Run → Builder (Timeline)
          → Interpolate(t) → gg canvas → ffmpeg stdin → out.mp4

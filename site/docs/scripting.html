Keyframe rules

Times are quoted-string seconds. Logos has no duration literals, so "0" and "1.5" are keys, never 0s. Keyframes sort by time, declare in any order. Numbers lerp, hex and named colors lerp per channel, point arrays lerp elementwise, strings snap to the earlier key. Out of range holds the edge, never extrapolates.

Builtins

scene(3, 30)                              -- duration, fps
shape("b", "circle", table{               -- name, kind, keyframes, optional group
    "0": table{x: 80, y: 240, r: 40, color: "#e64c40", ease: "easeInOut"},
    "3": table{x: 560, y: 240, r: 40, color: "#40e680"},
})
text("t", table{                          -- kind implied
    "0": table{content: "go", x: 320, y: 60, size: 48, color: "#ffffff"},
})
group("g", table{"0": table{x: 320, y: 180, scale: 1, rotate: 0}})
shape("c", "circle", table{"0": table{x: 0, y: 0, r: 20, color: "red"}}, "g")
audio("/path/to.mp3", 1.0)                -- path, offset, optional loop bool
camera(table{"0": table{x: 320, y: 180, zoom: 1}})
CallDoes what
scene(dur, fps)canvas length and frame rate, once per script
shape(name, kind, keys[, group])one animated entity of a kind from the kinds page
text(name, keys[, group])shape with kind implied
group(name, keys)container with keyframed x y scale rotate alpha layer; children use local x/y
audio(path[, offset][, loop])mux a track under the video; loop repeats to the last frame
camera(keys)pan and zoom the whole scene with x y zoom keys

Voice

let v = tts("hello world", "/tmp/out.mp3")                       -- default voice
let v = tts("hello world", "/tmp/out.mp3", "en-US-JennyNeural")  -- string shorthand
let v = tts("hello world", "/tmp/out.mp3",
    table{voice: "en-NG-EzinneNeural", rate: "+10%", pitch: "+0Hz", volume: "+0%"})
audio(v.audio)                             -- lay the narration under the video
for i, w in v.words {                      -- word timings for synced captions
    text("w" + str(i), table{
        str(w.start): table{content: w.word, alpha: 0},
        str(w.start + 0.08): table{content: w.word, alpha: 1},
        str(w.end + 0.12): table{content: w.word, alpha: 0},
    })
}
let voices = tts_voices()                  -- list Edge voices

Tries Edge neural first with exact word timings, falls back to espeak-ng, then beeps. Returns table{audio, duration, words}.

Easing

Per segment, declared on the earlier key: linear easeIn easeOut easeInOut cubicIn cubicOut cubicInOut sine. Example: "0": table{x: 0, ease: "easeInOut"}.

Templates and files

One script renders many videos. Leave names and copy as bare variables, feed per render with render --var title="Batch Alice". Long copy comes from disk: text_file("assets/copy.txt"), 1 MB cap, frozen at build time. Shared code inlines with use "helpers/spike", resolved beside the script.

Installer

curl -fsSL https://codetesla51.gitlab.io/kyfram/install.sh | sh

Pin a version: append sh -s -- v0.2.0, or VERSION=v0.2.0 sh install.sh. Re-run any time to update. Installs to /usr/local/bin, or ~/.local/bin when that is not writable.

Build by hand

git clone https://gitlab.com/codetesla51/kyfram && cd kyfram
go mod download
go build -o kyfram ./cmd/kyfram
./kyfram render --help
./kyfram view --help

Or straight from the module proxy, no clone: go install gitlab.com/codetesla51/kyfram/cmd/kyfram@latest.

Fonts

Text falls back to the bundled Archivo Black. Override per text with font:, per render with --font, or per timeline with Timeline.Font. Fonts must be .ttf. .otf/CFF fails under freetype and the text is skipped.

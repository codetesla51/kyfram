Two commands. render writes files, view opens a preview. help and --version included.

Overview Install Quickstart Scripting Kinds CLI Examples Concepts

render

kyfram render [--out f] [--fps n] [--width n] [--height n] [--font f]
              [--crf n] [--preset s] [--format mp4|png] [--var k=v ...] <script.lgv>
FlagMeaning
--outoutput path (default out.mp4, mp4 or png per --format)
--fpsoverride scene fps
--width --heightoverride canvas size (default 640x360)
--fontfallback typeface. Precedence: text font: prop, then --font / Timeline.Font, then built-in.
--crfx264 quality 0-51, lower is better (18 visually lossless, 23 default, 28 small)
--presetultrafast superfast veryfast faster fast medium slow slower veryslow
--formatmp4 via ffmpeg, or png single frame at t=0 with no ffmpeg
--var k=vrepeatable template vars, set before Run. Values may contain more equals signs.

view

kyfram view [--port n] [--font f] <script.lgv>

Serves a scrub slider, play button, and hot reload. Frames are PNG so saves are instant. Cached by file mtime, so scrubbing stays fast even with slow TTS.

Common runs

kyfram render examples/intro.lgv
kyfram render --out v.mp4 --crf 18 --preset slow examples/intro.lgv
kyfram render --format png --out frame.png examples/polygon.lgv
kyfram render --var title="Batch Alice" examples/vars.lgv
kyfram view examples/intro_voice.lgv   # → http://localhost:8080

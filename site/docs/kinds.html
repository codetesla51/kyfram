Shapes

KindProps
circlex y r color
rectx y (top-left) w h color
roundRectx y w h radius color, radius lerps
polygonpoints flat [x1,y1,…], color, filled? (default true), width. Closed. Same-length lists morph.
starx y r (outer), points count, inner 0-1 ratio, color
ellipsex y rx ry color. ry defaults to rx, r aliases rx.
linex1 y1 x2 y2 width color
arcx y center, r, start end in degrees, width color. 0..360 is a ring.
wavex y left baseline, width amplitude frequency (cycles) phase (degrees) thickness color. Zero amplitude is a straight line.
pathpoints flat list, width color, filled? closed? cap (round|butt|square) join (round|bevel)
imagepath x y, centered. Cached decode. Takes rotate/scale/layer, ignores alpha.
textcontent x y size color font?. points lays glyphs along the polyline, each rotated to its segment.

Unknown kinds and unloadable assets skip silently. One bad entity never kills the frame.

Shared props

Every vector kind takes alpha 0-1, rotate in degrees, scale, layer for paint order (lower first), ease per segment. Missing numerics fall back to canvas-centered defaults.

Color, gradients, blend

Hex or 24 named colors (red gold slate mint coral sky lavender …), case-insensitive, lerp exactly alike. Linear gradients on filled kinds: gradFrom gradTo plus gradAngle. Strokes and images stay flat. Blend on any entity: blend: "multiply" | "screen" | "add".

Groups

group(name, keys) with keyframed x y scale rotate alpha layer. Children keep local x/y and animate independently. Transform is translate, then rotate, then scale. Children sort by layer inside the group, groups interleave with root by layer. One level deep, nested groups are future.
